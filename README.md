## LightLayer 是什么，机房在哪

LightLayer 是 Megalayer 旗下的云服务器品牌，KVM 虚拟化，母机用 AMD EPYC 平台配 NVMe 固态。节点覆盖洛杉矶、圣何塞、香港、台湾、伦敦等地，网络分三档：Premium 优化线路走 CN2、CT、CU、CMI、PCCW、COGENT；Standard 标准线路；Global 国际线路。

优化线路的实际走向值得单独说一句。第三方测评记录显示，去程是电信、联通、移动各自直连美国西海岸节点后接 Cogent 进机房，回程则三网统一强制走移动 CMIN2（AS58807）回国。移动用户回程最顺；电信、联通用户能用，但走的不是各自运营商的最优回程。这一点在购买前需要知道。

## 同是 1 核 1G，$4 和 $5.60 差在哪

洛杉矶不限流量系列里，1GB 内存到 32GB 内存，每 GB 内存的单价从 $4.00 一路降到 $1.68。配置越高单价越便宜，但个人用户真正用得上的只有前两档。

1 核 1G 的 $4 是入口价，适合单个服务：一个静态站、一个代理节点、一台监控机、一个定时任务容器。跑 WordPress 加 MySQL 会比较紧张，装完面板和缓存插件后内存余量不多。

2 核 2G 的 $5.60 是这条产品线里最合理的一档。多付 $1.60，内存翻倍、CPU 翻倍、带宽从 20M 提到 30M。日访几百到几千的展示站、两三个 Docker 容器、小型数据库，这一档都能应付。

4 核 4G 的 $8.80 适合多站点、跑编译任务或需要更高并发。8 核及以上多数个人用户用不上，除非你在上面跑 CI、构建流水线或者容许多租户的容器集群。带宽在 2 核以上统一锁在 30M，加钱买的是 CPU 和内存，不是网速。

限流量系列和不限流量系列同价。区别在带宽和流量：限流量版给到 50Mbps、每月 1TB，不限流量版是 20–30Mbps、不限总量。1TB 摊到 30 天，平均持续 3.9Mbps 就能跑满，50Mbps 的峰值有十几倍余量。下载站、镜像源、短时高并发的场景选限流量版更合适；长期稳定跑量、流量难以预估的选不限流量版。

圣何塞两款差价一倍，买的是三样东西：SSD 换掉 HDD、带宽从 300Mbps 提到 1Gbps、流量从 500GB 提到 1TB。跑数据库或高并发读写的应用，HDD 的随机 IO 会先成为瓶颈，这时候 $9.90 的 SJ-VP04-L 值这个差价。只是放静态文件或做测试机，LITE 够用，但要注意它明确只支持 Linux。

## 哪些人买了会后悔

**需要 IPv6 的人**。测评记录显示 LightLayer 的 VPS 不支持 IPv6，只给 1 个 IPv4。如果你的业务依赖 IPv6 地址段，这台机器直接排除。

**需要 Windows 的人**。SJ-VP04-LITE 明确只支持 Linux。其他套餐是否支持 Windows，公开页面没有统一说明，下单前必须问客服，别默认可以。

**习惯支付宝或微信支付的人**。早期测评记录里 LightLayer 只收 PayPal，官方说后续会增加信用卡、加密货币和支付宝。现在支持到什么程度，以下单页的支付选项为准。只能 PayPal 的话，先确认自己的账户能用。

**想要香港大带宽的人**。香港节点最高 20Mbps，这是香港机房带宽成本决定的，同配置香港 VPS 普遍比美国贵、带宽普遍比美国小。要在香港拿 100Mbps 以上，LightLayer 目前不是选项。

**期待中国大陆低延迟、却买了 Standard 或 Global 线路的人**。优化线路才是 CN2、CMI 那一套。国际线路带宽数字好看，国内访问会绕。

**需要成文退款保障的人**。本次核验的公开页面里没有找到明确的退款条款。这不等于没有退款政策，但意味着你下单前应该先问清楚：几天内可退、退到哪里、是否扣手续费。没问就年付，出问题时没有依据。

## 下单前要确认的五件事

1. **计费周期和折扣是否适用于你选的套餐**。17% 的年付折扣在圣何塞页面有标注，其他机房是否同享要看清。
2. **续费价**。首期价和续费价是否一致，活动价是不是只给首年。这决定了第二年的真实支出。
3. **是否含独立 IPv4**。记录显示含 1 个，下单页再确认一次，额外 IP 通常另收费。
4. **端口默认是关闭的**。开通后所有端口默认阻止，需要进防火墙面板手动放行你要用的端口，SSH、HTTP、HTTPS 都要加。第一次用容易卡在这一步。
5. **流量超了怎么算**。限流量套餐（1TB 那几款）超出后是停机、限速还是按 GB 计费，下单前问清楚。
